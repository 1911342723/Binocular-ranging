Medición de distancia estereoscópica, interfaz PyQt5
Integración de calibración automática de cámara / calibración de cámara mediante entrada manual de parámetros
Incluye mapa de profundidad / imagen en escala de grises / nube de puntos
El mapa de profundidad permite medir la distancia y obtener coordenadas mundiales


# Inicio

Instale las dependencias eligiendo cualquier fuente de espejo para la instalación

Alibaba Cloud (Recomendado)

`pip install -i https://mirrors.aliyun.com/pypi/simple/ -r requirements.txt`

Universidad Tsinghua

`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple/ -r requirements.txt`

Huawei Cloud

`pip install -i https://repo.huaweicloud.com/repository/pypi/simple/ -r requirements.txt`

Tencent Cloud

`pip install -i https://mirrors.cloud.tencent.com/pypi/simple/ -r requirements.txt`

Douban (Protocolo HTTP, puede requerir --trusted-host)

`pip install -i http://pypi.douban.com/simple/ --trusted-host pypi.douban.com -r requirements.txt`


# Ejecución

Simplemente ejecute `main.py`
